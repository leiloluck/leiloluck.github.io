How it works

poltergeist.exe

Pick some sounds. Set how often they fire. Hit UNLEASH and lock your phone. Walk away.

Sounds play at random intervals around the time you set. With chaos timing on, each gap is between 0.75x and 1.25x the base interval - irregular enough that nobody can predict when the next one hits.

Everything is pre-scheduled on the audio clock, so sounds keep playing through a locked screen in almost all cases. No timers, no polling.

For the most reliable results: install poltergeist.exe from Chrome (Settings → Install to Home Screen) rather than running it in a browser tab, then check that Android isn't battery-restricting it, Settings → Apps → poltergeist.exe → Battery → Unrestricted. Once installed from Chrome it appears there under its own name, separate from the browser.

Brave: Brave can only add a shortcut, not a real installed app, so Android never gives poltergeist.exe its own battery setting and background sounds are more likely to be cut off. The app still works, but install from Chrome if you want it to survive a pocketed phone.

Works over Bluetooth. Connect your speaker before hitting UNLEASH. A near-silent signal runs in the background to keep the speaker awake during long gaps.

Use Test Mode to preview each sound before hiding the device. It exits the active session automatically.
