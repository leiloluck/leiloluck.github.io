# Jellinek — Resource Collection

**Organization:** Jellinek (part of Arkin mental health)
**Website:** https://www.jellinek.nl
**Location:** Amsterdam, Netherlands
**Helpline:** 088 505 1220
**Language:** Dutch and English
**Date accessed:** 2026-03-31

## About

Jellinek is one of the Netherlands' largest addiction care organizations, providing:
- Substance information (comprehensive online drug encyclopedia)
- Addiction treatment and counseling
- Prevention programs
- Self-assessment tests
- Free helpline (088 505 1220)

Their substance pages are available in English and provide accessible, evidence-based harm reduction information using the **Drug, Set, Setting** framework.

## Content Structure

Each Jellinek substance page contains:
- **What is it?** — Description and forms
- **Effects** — Using Drug/Set/Setting framework
- **Duration** — Onset and effects timeline
- **Dosage** — Route-specific ranges
- **Short-term risks** — Acute dangers
- **Long-term risks** — Chronic effects, dependence
- **Tips** — Practical safer use guidelines
- **Stop or cut down** — Guidance for reducing/quitting (separate page)
